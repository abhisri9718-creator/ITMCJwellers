# Adding real photos to the ITMC Jeweller app

Put JPG photos in this `photos` folder using the exact file names below, then upload the whole site folder to Netlify again. Any photo you add replaces the drawn jewellery automatically; anything missing keeps the drawing, so the site never shows a broken image.

Free photos for commercial use: Unsplash (unsplash.com) and Pexels (pexels.com). Square photos on a light background look best for products (at least 800×800).

Optional extra gallery angles: `rajwadi-2.jpg`, `rajwadi-3.jpg`, `rajwadi-4.jpg` (Angle, Detail, Velvet views). Without them the main photo is reused with a zoom.

Quick alternative without re-uploading: Admin panel > Products > Upload. That photo shows on the store in the same browser.
